## 做法
- 后端 `GET /staff/arrival-notices/list` 加 `warehouse`（四个仓 / `other` = 没选仓库 + 仓库不在这四个的老数据；认不出 = 全部），回包多 `warehouseCounts`。页签数字按选的仓数；仓库按钮数字按现在的页签和搜索词数、不管选了哪个仓。同一个可重复读快照里多一句 groupBy。
- 页面：页签上面一排「全部仓库 / 义乌仓 / 广州仓 / 东莞仓 / 深圳仓」带数字，「其他」有才出来（正看着它也出来）。每台电脑记住上次点的（`xt_arrival_list_warehouse`，读不了 / 认不出就看全部）；换仓回第 1 页；没取到时再点同一个仓会重拉。
- 我定的（技术 / 顺手的，没问他）：看着某个仓点「登记到货」仓库先填那个仓（看全部 / 其他照旧填上次登记选的）；存完不在正看的仓下面，提示多一句「这条在「X」下面，现在看的是「Y」，所以这里不显示」；空着时前面加「X仓：」。
- 「屏上这份不能当真」（审查加的）：条件换了新的没回来 / 没取到，或者存完挪走了一张卡还没刷新成（`outdatedAfter` + 取数号，只认标作废以后发出去的那次），列表 / 分页变灰 + inert，页签和仓库数字变淡，都晚 0.25 秒才显出来；旧的是空列表时说「正在加载…」。这条对换页签、搜索也生效（原来换页签时旧列表也能点）。挪仓存完用大声刷新（失败报错）。超管改已转运单改了仓、卡片刷新失败：说不准在哪个仓（改单接口顺手对齐那一步失败只记日志），不点名、照样作废 + 大声刷新。
- 老后端（上线那几分钟，没回 warehouseCounts）：整排藏起来、空列表不带仓名、存完不多说。
- 白底描边按钮，选中加深边（悬停也保持）；手机 40px 高、折行。
