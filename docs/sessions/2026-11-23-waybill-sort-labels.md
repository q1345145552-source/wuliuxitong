- 编辑弹窗（WaybillEditDialog，员工 / 管理员共用）格子名只写在 placeholder 里，一填就没了。长宽高其实是产品行第 3～5 格。
- 线上到仓日期（orders.ship_date，字符串）3346 张只有 1 张空，全是 YYYY-MM-DD；跟建单日期不是同一天的有 1521 张（补录 / 导入）；年份手误 3 张（SZ260702773 填 2026-12-30、YW0001305 填 0226-06-14、GZ260800533 填 0026-08-07），照填的排、不动数据。

## 做法
- 新 `apps/web/src/modules/shipment/waybill-sort.ts`：`waybillArrivalComparator(dayOf)` —— 到仓日期新的在上 → 同一天按录入时间（订单 createdAt）晚的在上 → 再按原来的运单号数字降序兜底；没填 / 不是真实存在的年-月-日（2026-02-31、2026-99-99）排最后。
- **排的日期 = 那一页「到仓日期」那一列显示的日期**（dsh 第 1 轮必须修）：员工页那一列只显示 shipDate → `compareWaybillsByArrival`；管理员页那一列没填时退到建单日期（待入库除外，`adminArrivedDate`）→ 模块顶上 `compareAdminWaybillsByArrival = waybillArrivalComparator(adminArrivedDate)`。线上没填到仓日期的只有 1 张（运单号 111，已装柜，建单 9-28），管理员页排进 9-28 那天、员工页排最后。不存在的日子那一列原样显示（留给人去改），排序当没填。
- `/staff/shipments` 回包加 `createdAt`（跟 `/admin/orders` 同一口径：订单建单时间，没有订单才用运单的）；前端 ShipmentItem 加可选字段（老后端没有时同一天按运单号）。
- 编辑弹窗：上面那排每格包 `<Named caption>`（div 不用 label：唛头下拉里有按钮），名字：唛头 运单号 柜号 仓库 运输方式 国内单号 收货地址 装柜号 包装 总重量(kg) 总体积(m³) 到仓日期；11 个原生格子各写 `aria-label`=名字（第一版用 cloneElement，test-staff-perms-source 的假 React 没有它 → 改成直接写）。产品行列名和所有格子放在同一个网格里（第一版列名单独一个网格，实看「箱数」跑到第三格上面——列宽按输入框算，两个网格各算各的），每格 aria-label「第 N 行 列名」、X「删除第 N 行」。
- 「国内单号」那格 placeholder 原来写「货拉拉」是提示空着会自动补货拉拉（d99d08f），名字写「国内单号」、提示字不动。
- 提速（老板说「先检查一下」后拿线上数据量出来的）：比较函数每比一次都重新解析日期，线上 3344 张排一次 16 毫秒（老排法 3 毫秒）→ 每行的「哪一天 / 录入毫秒」用 WeakMap 按行对象记住，`dayOf(row)` 的结果或 createdAt 变了就重算；每次新对象 2.4～2.8 毫秒。
- 没改：手机窄屏产品行要左右滑（改动前就这样，老板没提）。
